**PASS for the LM-21 slice.** Owned extra time at batch M4 is 0.178785 ms, below the requested 0.20 ms. Causal extra time is 0.181576 ms `[derived, detail_profile.py, summarize.py]`. The fork saves 0.462528 ms from a paired batch M4 full pass and 0.510336 ms from causal M4 `[derived, timing.json]`. This slice alone does not satisfy the full-pass 1.5x goal; its batch M4/M1 ratio remains 2.067389x.

All timed production and detailed-profile builds have zero spills `[measured, build-selected-m*.log, build-detail-m*.log, build-baseline-detail-m*.log]`.

## Status

Implementation is complete in `kernels/megakernel_pro/`; harnesses and retained evidence are in `bench/lm21/`. The requested inventory and unified kernel diff are `kernels/megakernel_pro/CHANGES.md` and `mega_mt.diff`.

- Residual updates flatten column/eight-element chunks across all threads. Each row retains the original local floating-point arithmetic, its four active warp sums, and the padded XOR reduction order. One warp per row computes the norm factor concurrently.
- Normalization staging flattens every column into one invocation and one publication barrier.
- Attention combine gives each head a full warp, broadcasts unchanged partial-softmax scales, reads aligned float2 pairs, and writes the inherited transposed activation layout. All columns publish together.
- SiLU reads contiguous eight-element chunks across all columns, computes the unchanged scalar arithmetic, and publishes transposed outputs together.
- Per-CTA argmax assigns disjoint physical warp groups to columns, then reduces all columns after one shared-memory barrier. Final token/history merging uses one warp per column. Tie-breaking still selects the lowest index.
- Per-column CTA barriers disappear from these owned invocations. Every grid barrier remains, so global phase count and schedules are unchanged. No schedule validation rerun was required by the unchanged-schedule contract.

No GEMM header, `attn2`, KV append, packed weight layout, cache layout, Python engine constructor, or C ABI was changed. Diagnostic wrapper and build changes only follow the new owned invocations and the exact `--fmad=false` compiler contract. `research/` was not used; no git writes were made.

## Honest negatives

The first 16-lane-per-head candidate reduced batch owned extra time to 0.232304 ms but missed the slice limit. Its paired batch full-pass saving was 0.423392 ms `[derived, initial/summary.json]`. The revised full-warp float2 combine and contiguous SiLU load mapping pass the slice gate. Sessions are separately paired; cross-session absolute times are not used to select a speedup percentage.

The first stock gate failed because it compared exact-contract output to LM-14's contracted M1 library, difference 0.145874 versus tolerance 0.1 `[measured, tiers.jsonl]`. The integrator fixed this generically with `gate_contract.json`, which also preserves compiler flags and thread counts in jitter rebuilds. The final stock gates pass; no bounds were weakened. The initial failure and scoped diagnostic gate results remain as evidence.

The full-pass batch and causal M4/M1 ratios are still 2.067389x and 2.021505x, respectively. This is a useful slice winner, not a full-kernel 1.5x success. No tier-3 qualification, large-context throughput claim, stochastic sampling claim, or hardware-counter attribution is made.

## Reproduction

Run from the repository root. Each GPU job is bounded inside the shared-lock wrapper.

```sh
bash kernels/megakernel_pro/build.sh selected
bash bench/lm21/build_profile.sh
scripts/gpu.sh timeout 285 .venv/bin/python bench/lm21/check_gate.py
scripts/gpu.sh timeout 285 .venv/bin/python gate/run.py --engine mt --m 4 --mode batch --lib kernels/megakernel_pro/libmt4.so --tier 2
scripts/gpu.sh timeout 285 .venv/bin/python gate/run.py --engine mt --m 4 --mode causal --lib kernels/megakernel_pro/libmt4.so --tier 2
scripts/gpu.sh --timing timeout 285 .venv/bin/python bench/lm21/bench.py
scripts/gpu.sh --timing timeout 285 .venv/bin/python bench/lm21/detail_profile.py
.venv/bin/python bench/lm21/summarize.py
```
